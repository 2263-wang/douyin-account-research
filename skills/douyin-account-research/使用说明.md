# 抖音账号与选题调研工具包

一套可复用的抖音对标账号分析工具。给一个账号或一个选题关键词，自动采集数据并产出**竞品数据表、账号内容框架分析、评论区选题库**。

## 包含什么

```
douyin-account-research/
├── SKILL.md / README.md / REFERENCES.md / EXAMPLES.md   skill 指令与文档
├── install.ps1            安装到 Codex 个人 skill 目录
├── verify-env.ps1         环境自检（先跑这个）
├── scripts/               分析层：编排、适配、报告、逐字稿
│   ├── run.mjs            三个模式的编排器（主入口）
│   ├── analyze.mjs        分析引擎 → Markdown 报告
│   ├── resolve-account.mjs 昵称 → secUid
│   ├── fetch-detail.mjs   详情接口精采（拿 DOM 拿不到的字段）
│   ├── transcribe.mjs     抽音轨 + 转写 → 逐字稿
│   ├── normalize.mjs      输入归一化
│   └── lib/               CDP 客户端、输出形状适配
├── toolkit/               采集层：驱动真实浏览器的脚本
│   ├── launch.ps1         起带调试端口的 Chrome
│   ├── crawl.js           关键词搜索
│   ├── works.js           抓账号主页与作品列表
│   ├── vstats.js          逐条视频的真实互动
│   ├── comments.js        抓评论
│   ├── dates.js           发布日期
│   └── ...                merge/candidates/rank/engagement/find/vsrch 等
└── examples/              示例数据（可直接离线试跑，不含任何登录态）
```

## 安装

**Windows**

```powershell
powershell -ExecutionPolicy Bypass -File verify-env.ps1          # 环境自检
powershell -ExecutionPolicy Bypass -File install.ps1             # 装到 Codex skill 目录
```

**macOS / Linux**

```bash
bash verify-env.sh          # 环境自检
bash install.sh             # 装到 ~/.codex/skills/
```

也可以不安装，直接在包目录里跑。

> 两个平台的自检脚本都是包装，真正逻辑在 `scripts/verify-env.mjs`，跨平台共用一份。

## 支持的系统

**Windows / macOS / Linux 都支持。** 采集与分析全部用 Node 写，浏览器自动定位。

### 浏览器怎么找的（两级）

| 顺序 | 找什么 | 范围 |
|---|---|---|
| **1** | Chromium 系：Chrome / Chrome Beta / Chromium / Brave / Vivaldi / Opera | Windows 查 `Program Files`、`Program Files (x86)`、`LOCALAPPDATA` 三处；macOS 查 `/Applications` 和 `~/Applications`；Linux 用 `which` |
| **2** | **Edge**（兜底） | 同上。Windows 10/11 基本自带，所以"没装 Chrome"也能直接跑 |
| 都没有 | 提示你去装 | 脚本**不会自动下载** |

所以正常情况下你什么都不用配：装了 Chrome 就用 Chrome，只有 Edge 就用 Edge。

### 两级都没有才需要动手

```bash
# 装一个（Windows/macOS 自带 Edge，通常不用做这步）
#   Chrome: https://www.google.com/chrome/
#   Linux : sudo apt install chromium
```

如果已经装了但不在上面的查找范围里（绿色版、自定义目录），直接指定路径：

```powershell
set DSH_BROWSER=D:\path\to\chrome.exe            # Windows
```
```bash
export DSH_BROWSER=/path/to/chrome               # macOS / Linux
```

启动器会把自己选中的浏览器通过 `DSH_BROWSER` 传给采集脚本——**不用你手动配两遍**。

> 国产浏览器（360、QQ 等）大多也是 Chromium 内核，理论可用但没测过；要用请用上面的环境变量指定路径。

### 各平台入口

| 操作 | Windows | macOS / Linux |
|---|---|---|
| 启动浏览器 | `node scripts\launch.mjs` | `node scripts/launch.mjs` |
| 环境自检 | `verify-env.ps1` 或 `node scripts\verify-env.mjs` | `verify-env.sh` 或 `node scripts/verify-env.mjs` |
| 关闭浏览器 | `node scripts\close-browser.mjs` | `node scripts/close-browser.mjs` |
| 采集与分析 | 一致 | 一致 |

> `toolkit/launch.ps1`（Windows）和 `toolkit/launch.sh`（macOS/Linux）都是便利包装，最终都调用同一个 Node 启动器。

## 三个模式

**Windows**

```powershell
# 选题调研（需要登录态）
node scripts\run.mjs --mode topic --keyword "AI编程"

# 对标账号分析（默认只分析最近 30 天）
node scripts\run.mjs --mode account --account "某账号昵称"
node scripts\run.mjs --mode account --account "https://www.douyin.com/user/MS4w..." --days 90

# 评论区选题挖掘
node scripts\run.mjs --mode comments --works works-xxx.json
```

**macOS / Linux**：把 `scripts\` 换成 `scripts/`，其余完全相同。

跑完会自动出报告（`report-account.md` / `report-comments.md`），并**自动关闭它启动的浏览器**。

**离线试跑**（不需要登录、不需要浏览器）：

```bash
node scripts/run.mjs --analyze-only --mode account --inputs ./examples --outdir ./demo-out
```

## 环境要求

| 组件 | 必需 | Windows | macOS / Linux |
|---|---|---|---|
| Node.js ≥ 18 | ✅ | [nodejs.org](https://nodejs.org) | 同左（**不需要 npm install**） |
| Chrome / Edge / Chromium / Brave | ✅ | 装一个即可 | 同左 |
| ffmpeg | 转写需要 | `winget install Gyan.FFmpeg` | `brew install ffmpeg` / 发行版包管理器 |
| Python 3 + faster-whisper + opencc | 转写需要 | `pip install faster-whisper opencc-python-reimplemented` | 同左 |

## 第一次使用

1. 起浏览器：`node scripts/launch.mjs`（Windows 也可 `powershell -File toolkit\launch.ps1`）
2. 在窗口里**扫码登录抖音**（建议用小号）
3. 保持窗口开着，回去跑 `run.mjs`

登录态存在 `toolkit/profile/` 里，**下次打开就是登录状态，不用重复扫码**。这个目录**不要**复制给别人。

## 为什么必须开浏览器

抖音的搜索与详情接口需要登录态 + 请求签名。实测三条路：

| 做法 | 结果 |
|---|---|
| HTTP 客户端直接请求 | 返回空壳页（可见文本 0 字） |
| headless 浏览器 | 渲染成功，但服务端返回"验证码中间页" |
| **可见窗口 + 人工登录** | ✅ 通 |

所以采集层驱动真实浏览器：真实鼠标点击搜索框、逐字符输入、随机间隔、滚动加载。**脚本不构造请求、不签名、不绕验证码。**

## 能拿到什么 / 拿不到什么

| 数据 | 能拿 | 说明 |
|---|---|---|
| 作品列表、标题、点赞、时长、发布日期 | ✅ | 主页 + 逐条详情 |
| 评论（含正文/时间/地区/点赞） | ✅ | 滚动加载 |
| 分享数、收藏数 | 部分 | 收藏数 DOM 上没有，需走 `fetch-detail.mjs` |
| 逐字稿 | ✅ | 抽音频 → faster-whisper 转写（CPU 约 2.6 倍速） |
| **播放量、完播率** | ❌ | 接口不返回。**报告里不会编这两项** |

## 评论区的判读规则（这个工具包的核心）

评论**不是**按"提问/索取/质疑"分类，而是按**有没有信息增量**分四层：

| 层 | 内容 | 用途 |
|---|---|---|
| **S 观点型** | 含矛盾 / 专业约束 / 反向主张，**且给了理由** | 直接做选题，标题常藏在原话里 |
| **A 细节型** | 含可验证的具体细节（行话、版本、失败场景） | 挖干货 |
| **B 资源型** | 求邀请码 / 求链接 / 求名额 | **运营信号，不是选题** |
| **C 噪声** | 作者自己的回复、灌水、纯表情、过短 | 丢弃 |

> 有效 ≠ "提问"。「如何获取邀请码呢？」和「为什么我的也转圈圈了」都是提问，但后者含可验证的失败细节，前者没有。

**高赞 ≠ 高价值**：高赞榜里常见"求码"和情绪表达。选选题看报告的第九节，不要看高赞榜。详见 `EXAMPLES.md`。

## 已知限制

- **播放量/完播率拿不到**，报告不编。
- **主页只显示相对时间**，部分作品解析不出绝对日期，时间窗过滤会排除它们。
- **展开的回复会被拼进上一条评论**（工具链读的是整块 innerText）。修法已写在 `REFERENCES.md`。
- 抖音在持续改版，DOM 选择器可能需要跟着更新。

## 边界

- 不做批量抓取、不构造带签名的请求、不绕过验证码
- 只下载音频用于转写分析，不下载视频原件、不再分发
- 采集节奏按人类速度设计；连续快速点开多个视频会触发风控组件
