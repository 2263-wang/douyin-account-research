# 报告写法范例

`analyze.mjs` 会生成骨架和全部数据表格。**这个文件说明怎么把数据写成结论**——脚本给数字，判断由你来做。

---

## 一、选题调研报告：从数字到判断

### 脚本给的表

```
时长区间      条数   占比    点赞中位数
≤30s          4     23.5%   12.4万
31–60s        2     11.8%   33.9万
1–3min        2     11.8%   5.1万
3–6min        1      5.9%   3.3万
6–15min       2     11.8%   23.5万
>15min        0      0.0%   —
```

### 你的判断（这才是交付价值）

> **供给缺口在 31–60 秒和 6–15 分钟。**
> - 31–60 秒只有 2 条，但点赞中位数 33.9 万——样本少、天花板高，是"少人做但做得动"的区间。
> - 1–3 分钟有 2 条但中位数只有 5.1 万，说明这个区间**供给多、竞争同质**，是红海。
> - 6–15 分钟 2 条都进了前列，说明长内容在这个题材里**不被劝退**，只要密度够。
>
> **建议**：首发做 40–60 秒（上限高、易起量），第二期做 8–12 分钟（承接收藏）。

**规则**：不要只贴表。每条表后面必须有一句"所以呢"。

## 二、比率怎么读

| 比率 | 数值 | 判断 | 对应动作 |
|---|---|---|---|
| 收藏/点赞 | 0.42 | **工具型内容**（正常娱乐内容 0.05–0.15） | 观众要"回头照着做"→ 内容要给可操作的清单、参数、步骤，不要只给观点 |
| 收藏/点赞 | 0.08 | 情绪型内容 | 观众看完就走 → 靠情绪浓度和转发，别指望收藏 |
| 评论/点赞 | 0.20 | 评论区是主战场 | 必须设计互动装置（提问、征集、承诺发资料） |
| 评论/点赞 | 0.02 | 观众只看不说 | 内容自洽即可，互动设计投入产出比低 |

**实测案例**：某条视频把"评论区留言我就把这份资料发给你"放在第 21 秒，换来 4.8 万评论 + 12.6 万收藏（收藏/点赞 0.54，全样本最高）。**这句话不是内容，是互动装置。**

---

## 三、开场模板的分类与产出

把逐字稿前三句拉出来，归成三类：

| 类型 | 原型 | 特征 | 适合 |
|---|---|---|---|
| **时代宣言** | 我宣布，所有人已经从"表演生活"进入"纯过日子"时代了 | 第一句给世界观，不介绍主题 | 泛人群、要广度 |
| **热度播报** | 不知道大家有没有看最近爆火的这个… | 借势，赌观众也刷到过 | 追热点 |
| **感悟开场** | 人到了一定年纪才明白，人生最大的浪费不是花错钱 | 先共鸣 3 句，再抖出"我发现了一个方法" | 要深度、要收藏 |

**关键判断**：三种模板在同一题材下**都爆过**（33.9 万 / 24.7 万 / 23.9 万赞）。所以模板之间没有优劣，**只匹配账号人格**。报告里要明确写这句，避免用户误以为"必须用最火的那个"。

## 四、对标账号报告：可复制 vs 不可复制

这是账号分析最容易写空的地方。**必须做这个切分**：

| 维度 | 可复制 | 不可复制 |
|---|---|---|
| 开场结构 | ✅ 三种模板任选 | |
| 内容密度 | ✅ 每 15–20 秒一个信息点 | |
| 清单形态 | ✅ "N 条我受益的建议" | |
| 互动装置 | ✅ "留言我发你" | |
| 口音/方言 | | ❌ 人格资产 |
| 个人经历 | | ❌ 信任状 |
| 出镜形象 | | ❌ 辨识度 |

**结论句式**：
> 这个号真正难抄的不是结构（结构 30 分钟就能学会），而是它把"我是这个领域里吃过亏的人"这件事建立起来了。你能抄的是它的开场和清单形态，抄不了它的经历——所以要么补一个自己的经历，要么把"专业可信"换成别的信任状。

## 五、评论区挖掘：先分层，再谈选题

**这是最容易做错的一步。** 核心原则：

> **有效 ≠ "提问"，而是"含信息增量"。**
> 「如何获取邀请码呢？」和「为什么我的也转圈圈了」都是提问，但后者含可验证的失败细节，前者没有。

### 四层分类

| 层 | 内容 | 用途 |
|---|---|---|
| **S 观点型** | 含矛盾 / 专业约束 / 反向主张，**且给了理由** | 直接做选题，标题常藏在原话里 |
| **A 细节型** | 含可验证的具体细节（行话、版本号、失败场景） | 挖干货内容 |
| **B 资源型** | 求邀请码 / 求链接 / 求名额 | **运营信号，不是选题** |
| **C 噪声** | 作者自己的回复、灌水、纯表情、过短 | 丢弃 |

打分：矛盾 +5 / 细节 +3 / 反向 +2 / 有理由 +2 / 长文 +2。**S ≥ 4，A ≥ 3，其余进噪声。**
门槛必须硬——放宽到 2 会让 A 层膨胀到占 60%，等于没筛。

### 三条真实评论的对照（实测）

| 评论 | 判定 | 理由 |
|---|---|---|
| 「听你说 ai 视频这么牛，为啥你的视频还坚持传统手搓🐶」 | **S，最有效** | 用作者自己的内容反驳作者的主张。**矛盾自洽性攻击**，无法辩解、必须正面回应，而且标题就是原话 |
| 「这种批量生成图片和视频的能力，只能说适合氪金设计师😭，费片率很高」 | **S/A，有效** | **带专业度**（"费片率"是内行词）+ 具体约束 + 隐性需求：观众真正的坎是成本和稳定性 |
| 「如何获取邀请码呢？」 | **B，无效** | 索取资源，**零信息增量**。做成视频只能变成导流/发码，还会被平台判引流 |

**关键区分**：不要用"是不是问句"筛，要用"**这句话里有没有我做内容能用的信息**"筛。

### B 层的正确用法（别浪费）

资源索取占比本身就是**需求强度证据**。实测某账号 1246 条评论里资源型占 ~10%，说明观众卡在**入口**不是**方法**——内容已经把需求激发出来了，交付链路断在"拿不到"。

三种用法：
1. 当**需求强度指标**写进报告（不用来做视频）
2. 设计成**互动装置**（"评论区留言我发你"）
3. **反过来做一期**：「拿不到邀请码时怎么办」——把索取转成内容

### 输出的报告长什么样

```
## 七、评论区：观众在关心什么     ← 四层分布表 + 资源索取占比
## 八、高频意群                   ← 已滤掉灌水和资源索取
## 九、可直接做选题的评论          ← S 层带分数标签，A 层次之
## 十、资源型需求（运营信号）        ← 明确标注"别当选题"
## 十一、高频评论 TOP 20           ← 提醒"高赞 ≠ 高价值"
## 十二、怎么把评论变成选题          ← 信号 → 动作对照表
```

**第十一节那句提醒很重要**：高赞榜里经常是"求码"和情绪表达。实测该账号的高赞评论里，价值最高的一条（9 分，讲"AI 时代最大的骗局是技术平权"）**不在高赞前列**。**选选题看第九节，不要看高赞榜。**

## 六、内容类型分析：看"观众这一个月在为哪类内容买单"

比单看时长/标签有用得多。做法：把作品按内容类型归类，再交叉三个比率。

### 通用类型表（跨账号可比）

| 类型 | 判定特征 |
|---|---|
| 知识教学 | 教程、入门、方法论、手把手、怎么用 |
| 产品评测 | 测评、实测、开箱、对比、值不值 |
| 行业解读 | 格局、趋势、上市、估值、洗牌、领先/落后 |
| 观点输出 | 我认为、反驳、误区、争议、值得吗 |
| 原理科普 | 原理、是什么、底层、论文、机制 |
| 资讯速递 | 发布、上线、更新、首发 |
| 故事案例 | 人物志、访谈、案例、一次难忘的经历 |
| 职业成长 | 职场、面试、简历、转型、副业 |
| 泛生活/其他 | 猫狗、美食、旅行、游戏、电影 |

### 关键：三个比率分别代表什么

| 指标 | 观众的意思 | 你要做什么 |
|---|---|---|
| **点赞中位数** | "这条好" | 这是账号当前的**流量主力**类型 |
| **藏/赞** | "以后用得上" | 这类适合做**沉淀**（工具书式内容） |
| **分/赞** | "想给别人看" | 这类适合做**涨粉**（观点、段子、金句） |

**收藏最高的类型 ≠ 转发最高的类型，这是常态。** 报告会自动指出这个分裂：
> ⚠ 收藏最高的类型 ≠ 转发最高的类型：前者是"以后用得上"，后者是"现在想给别人看"。
> 做选题时按目的选类型：要涨粉做「X」，要沉淀做「Y」

### 实测案例（三个同赛道账号，同一套类型表）

| 账号量级 | 流量主力 | 数据 | 观察 |
|---|---|---|---|
| 千粉级新号 | **行业解读** | 点赞中位 773 | 泛知识类的藏/赞达 0.545，但点赞只有 11 → **"值得收藏"和"能传播"是两件事** |
| 百万粉·AI 教程 | **知识教学** | 点赞中位 58.5万 | 教学内容的点赞是"资讯速递"（7.5万）的 **7.8 倍** |
| 百万粉·财经科普 | **资讯速递** | 点赞中位 5.8万 | 供给最大的是行业解读（42 条 / 33%），但点赞中位只有 1.1万 → **量大 ≠ 有效** |

**从这三组数据能提炼的通用判断**：
- 同一个账号里，**占比最高的类型往往不是点赞最高的类型**——供给结构反映的是创作者的舒适区，不是观众的偏好
- 找机会位要看**"占比低但点赞中位高"**的类型（供给缺口），而不是看哪类做得最多

### 用的时候要知道的边界

- **准确率约 79%**（实测 11/14）。启发式规则，必然有误判，所以报告里给出每条的代表作和命中词供人工复核
- **未分类超过 20% 会告警**：说明该账号内容超出通用表，要在 `lib/content-type.mjs` 里补规则
- **两个实测过的误判陷阱**（都已被规则规避，记下来免得再踩）：
  1. **别把话题标签喂给分类器**。`#大模型架构` 这个标签曾把"为何 Claude 领先 GPT"误判成「原理科普」
  2. **小心一词多义的比喻用法**。裸词「游戏」曾命中"美元霸权**游戏**""价格**游戏**"这类金融比喻，把财经内容误吸进「泛生活」。所以限定成 `手游|网游|玩游戏|游戏攻略`

## 七、报告里必须写的局限性（照抄这个格式）

```markdown
## 数据说明

- 来源：抖音搜索接口与详情接口，由用户登录态下的浏览器发起请求，非官方开放平台数据。
- 抖音接口不返回**播放量**和**完播率**，因此本报告不含这两项指标，也不做相关推断。
- 样本量：视频 N 条 / 评论 M 条，采集时间 YYYY-MM-DD。搜索页只采了第 1 页（has_more=1，后面还有）。
- 抖音数据实时变化，本报告是**某一时点的快照**，不是平台的长期结论。
- 其他平台（B站/小红书/知乎）的数据为公开可见信息，未经接口核验。
```

## 八、一句话总结模板

报告最后给一段"如果只记一句"：

> **如果只记一句**：这个题材里，收藏率是娱乐内容的 3–8 倍，说明观众在**存档**而不是在看热闹；而全样本收藏率最高的那条，靠的不是内容更好，是它在第 21 秒说了一句"留言我发给你"。
> 所以你要做的不是"讲得更精彩"，而是"给一个值得存下来的东西"。
